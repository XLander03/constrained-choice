# data/ — SYNTHETIC

Everything in this folder is **synthetic** and generated by `scripts/` with a fixed seed.

- `catalog.csv` — 299 invented distributor SKUs. Real brand names appear only as generic catalog entries; every price,
  case size, SKU id and alias is made up and must not be read as real pricing or a real distributor's range. Each row has `data_label=SYNTHETIC`.
- `orders.jsonl` — 150 invented retailer orders (WhatsApp and email style) with gold labels per line
  (`sku_id`, `qty`, `unit`; `ambiguous` + `acceptable_sku_ids`, or `out_of_catalog`). Each record has `data_label: "SYNTHETIC"`.

Known limitation: orders are generated from the same alias lists that populate the catalog, so extraction and retrieval
scores on this set are optimistic. The 15 hand-written orders (tag `handwritten`) are the harder slice. Replace with real,
consented, anonymised orders before trusting any number.

Regenerate: `npm run gen:catalog && npm run gen:orders`.
